🚀 專題 3 項具體改善紀錄 (前後對照)

改善紀錄 1：視覺緊張度回饋
原本問題：初版純文字數字輸入，在縮小區間時缺乏臨場緊張感。
修改決策：設計動態安全色條與自適應氛圍燈（綠→黃→紅急促閃爍），並用 Web Audio API 合成即時心跳音效。
驗證證據：現場測試時全體組員明顯感受到範圍小於 10 時的壓迫感，刺激感大幅提升！
改善紀錄 2：實作派對多人模式與懲罰 CRUD 題庫
原本問題：傳統單人猜數字容易流於反覆算數，缺乏派對多人互動與趣味懲處。
修改決策：加入多人輪流模式，並建立「命運懲罰題庫 (CRUD)」，輸家即時抽卡執行真心話大冒險。
驗證證據：新增自訂卡片與編輯功能後，可因應不同聚會場合隨意切換搞笑、真心話或請客玩法！
改善紀錄 3：行動觸控友善與虛擬撥號鍵盤
原本問題：手機瀏覽時每次點擊輸入框皆會彈出系統軟體鍵盤，遮擋畫面且輸入緩慢。
修改決策：在畫面上設計霓虹撥號按鍵 (0-9、Backspace、Clear)，同時支援電腦 Enter 與實體鍵盤。
驗證證據：在手機與筆電上測試輸入反應，每輪猜測操作速度縮短 50% 以上，體驗流暢。
