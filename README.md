## 🎯 專案簡介與設計核心 (Concept & Overview)

傳統的「終極密碼」通常僅在紙上或黑板上記錄，缺乏派對臨場感與視覺回饋。本專案 **CipherBomb** 從商業設計系的角度出發，結合 **Cyber-Arcade 霓虹美學**、**微互動動畫** 與 **Web Audio API 原生音效合成技術**，將經典的 1-100 猜數字轉化為兼具臨場緊張感與派對懲罰機制的互動網頁應用！

---

## ✨ 核心功能亮點 (Key Features)

### 1. 經典終極密碼核心機制 (1-100)
- **視覺化動態區間條**：隨猜測即時縮減安全區間，直觀感受步步進逼的壓迫感。
- **三階段自適應緊張度氛圍燈**：
  - 🟢 安全階段（剩餘 > 25）：平靜青紫呼吸光。
  - 🟡 警戒階段（剩餘 11~25）：警示金黃呼吸燈，觸發警戒心跳音效。
  - 🔴 極限危險階段（剩餘 ≤ 10）：急促紅色警報閃爍，炸彈劇烈震顫！
- **虛擬霓虹撥號鍵盤**：0-9 快速點擊，支援電腦實體鍵盤（Enter/Backspace）與手機平板觸控防誤觸。

### 2. 三大多元遊玩模式
- 👤 **單人闖關模式**：AI 隨機生成終極密碼，挑戰最少步數極限。
- 👥 **多人派對模式 (輪流踩雷)**：支援自訂參與玩家名單，自動記錄當前輪到誰輸入，踩中炸彈者即時處罰。
- 👑 **魔王出題模式**：派對主理人可暗中輸入指定數字（密碼全自動遮蔽），由現場親友輪流猜測！

### 3. 完整 CRUD 資料管理系統 (滿足期末加分 10 分規範)
本系統內建 **雙重 LocalStorage 資料庫**，無須後端資料庫即可持久化儲存：
- **🃏 命運懲罰題庫管理系統**：
  - **Create（新增）**：自訂派對卡片挑戰（名稱、詳細描述、分類標籤、1~5 星難度）。
  - **Read（查看）**：支援卡片網格展示、分類標籤切換（搞笑幽默、體能大冒險、真心話拷問、友情請客）。
  - **Update（編輯）**：隨時修改卡片標題、懲罰強度與內容細節。
  - **Delete（刪除）**：可自訂刪除過時卡片，並具備「一鍵還原預設題庫」功能。
  - 🎲 **踩雷自動抽卡**：遊戲引爆當下自動從題庫中抽取一張命運卡片，並附帶粒子爆炸全螢幕彩帶動畫！
- **🏆 歷史戰績英雄榜系統**：
  - **Create**：每次引爆自動記錄局數、玩家名、猜題步數、引爆數字。
  - **Read**：總對局數、平均步數、引爆次數與「踩雷王」數據儀表板。
  - **Update**：可編輯每筆戰績的玩家暱稱與心得備註。
  - **Delete**：支援單筆紀錄刪除與批量清空。

## 🛠️ 本機執行與部署上線 (Deploy to Vercel)

### 本機預覽
直接在瀏覽器開啟 `index.html`，或在終端機啟動本機伺服器：
```bash
python3 -m http.server 3000
```
瀏覽器訪問 `http://localhost:3000` 即可暢玩。

### 部署到 Vercel (加分項目)
1. 在 GitHub 建立公開專案庫 (Public Repository)。
2. 將本專案檔案推上 GitHub：
   ```bash
   git init
   git add .
   git commit -m "feat: complete CipherBomb ultimate password party game with CRUD"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/<專案名稱>.git
   git push -u origin main
   ```
3. 前往 [Vercel](https://vercel.com/)，點擊「Add New Project」並匯入該 GitHub Repo。
4. 預設 static 專案無須設定 Build Command，點擊 **Deploy** 即可一鍵取得公開網址！
